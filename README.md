# Reverie

Reverie is a self-hosted Rec Room revival server software project inspired by [RebornRec](https://github.com/aqquad/RebornRec), aiming to bring back the experience of older Rec Room versions.

With a goal of supporting Rec Room clients from 2016–2023, Reverie allows users to host and manage their own revival servers, preserving different eras of Rec Room for the community.
